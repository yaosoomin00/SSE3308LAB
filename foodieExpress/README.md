# FoodieExpress

A responsive food-delivery website built with React, Vite, Tailwind CSS, and DaisyUI.

## Run locally

From this folder, install dependencies and start the development server:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To check the production build and lint the
source, run:

```sh
npm run build
npm run lint
```

## Project stages

Stage 1 establishes the responsive homepage layout, navigation, restaurant
cards, category selection, and restaurant search. Cart, checkout, accounts, and
order tracking will be added in later stages.
